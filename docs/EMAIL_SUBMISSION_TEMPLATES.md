# BlogrXiv Email Submission Templates

GitHub Discussions and Pull Requests are preferred because they keep review state visible and auditable. Email is available when a submitter cannot use GitHub.

Send submissions to:

```text

wanghanqing0424@gmail.com
```

## Blog Link Recommendation

Subject:

```text
BlogrXiv Blog Link Recommendation
```

Body:

```text
Blog title:
Canonical URL:
Author / lab / organization:
Source name:
Suggested BlogrXiv category:
Suggested tags:
Are you the author?
Short summary:
Why is it technically valuable?
Related paper / code, optional:
Submitter contact, optional:
```

## Original Writing Submission

Subject:

```text
BlogrXiv Original Writing Submission
```

Body:

```text
Working title:
Author:
Author URL:
Suggested BlogrXiv category:
Suggested tags:
Canonical URL, if any:
License / permission statement:

Summary:

Why this is valuable:

Article Markdown:

References:
```

Original writing should be sent as Markdown in the email body or as a Markdown attachment. The submitter must confirm they wrote the work or have permission to submit it for BlogrXiv review.
