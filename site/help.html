How the index works: recommending posts, submitting original writing, editorial review, and reporting issues.

Frequently Asked Questions

How does a blog get into the index?

BlogrXiv does not publish drafts and is not a hosting platform. There are two intake paths: recommend an existing public post (yours or someone else's) through a GitHub Discussion or the submission page, or submit original Markdown writing through a pull request. Editors review every candidate against five criteria — technical contribution, specificity, source quality, reusability, and taxonomic fit — and only accepted work is added to the index, always linking back to the canonical source.

What kinds of pages are not indexed?

Lab or personal homepages, GitHub organization indexes, product landing pages, shallow release announcements, and paper-only pages without independent narrative are out of scope. Recommendations should point at a specific post that explains a mechanism, method, system behavior, or research lesson.

How are categories assigned?

Recommenders and authors suggest a category; editors make the final assignment using the boundary notes on the taxonomy page. Each entry is placed on exactly one of the eleven shelves, with secondary themes carried by topic tags.

Can AI tools be used in original writing submissions?

Yes, with disclosure. The submitting author remains responsible for factual accuracy, originality, and proper citations, and purely AI-generated content without meaningful human authorship is not accepted.

How do I report an issue or request a correction?

Email juanxitian1031@gmail.com with links and context, or open a GitHub Discussion. Indexed entries can be corrected or removed, and every editorial decision is recorded publicly when a GitHub record exists.

Making a Strong Recommendation

Name the contribution

State what the post teaches: the mechanism, method, implementation detail, evaluation insight, or research lesson that makes it worth indexing.

Make provenance legible

Provide the canonical URL and identify the author, lab, or organization, so editors can verify source quality and attribution.

Suggest placement

Propose one category from the taxonomy and a few topic tags. Editors confirm the final shelf using the published boundary notes.
