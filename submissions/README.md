# Original Writing Submissions

BlogrXiv accepts original technical AI research writing through GitHub Pull Requests. This path is for work you wrote yourself, or work you have permission to submit for publication review. If GitHub is unavailable, you may email the same materials to the maintainers.

If your article already lives on your own website, blog, newsletter, or lab page, please use the Blog Recommendation discussion form instead. BlogrXiv will review the canonical URL and, if accepted, index the original source.

## How to Submit Original Writing

1. Fork the repository.
2. Copy `submissions/template.md`.
3. Rename the file using a stable lowercase slug, such as `submissions/2026-07-20-author-short-title.md`.
4. Fill out the front matter, author confirmation, summary, article body, and references.
5. Open a Pull Request.

If you submit by email, include the completed front matter, author confirmation, summary, value statement, article body, and references in the message body or as a Markdown attachment. Email submissions are reviewed under the same editorial criteria as Pull Requests.

Accepted submissions may be indexed, edited for metadata and formatting consistency, or published as static BlogrXiv content. Submission does not guarantee publication.

## Editorial Expectations

Original writing should provide technical depth, implementation detail, evaluation insight, methodological reflection, or a durable research perspective. BlogrXiv does not publish low-information summaries, pure announcements, promotional copy, uncredited copied material, or content outside the AI research writing scope.

By submitting original writing, you confirm that you own the rights to the content or have permission to submit it. You grant BlogrXiv permission to review, edit for metadata and formatting, and publish the work on the BlogrXiv website and repository if accepted.
